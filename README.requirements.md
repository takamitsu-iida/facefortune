# 要件定義書：AI顔占い＆印象管理アプリ「FaceFortune」

## 1. 概要
本アプリは、顔認識技術と統計的占い・心理学を融合させ、ユーザーの表情を分析し、状況（ビジネス・恋愛等）に応じた開運アドバイスおよびメイク・身だしなみの指導を行う。特にリモート会議直前の「印象管理」に特化した価値を提供する。

## 2. ターゲットユーザー
- 仕事で成果を出したいビジネスパーソン（リモート会議・面接を控える層）
- 自己研鑽のために、客観的な自分の印象を知りたい人
- 運気や開運行動を日常生活に取り入れたい層

## 3. 主要機能

### 3.1 顔解析エンジン
- **リアルタイムトラッキング:** MediaPipe/ARKitによる顔パーツ（目・眉・口・輪郭）のリアルタイム位置取得。
- **指標スコアリング:**
    - 「信頼感」「親しみやすさ」「活力」「冷静さ」などを数値化。

### 3.2 モード別診断（カテゴリー選択）
- **ビジネスモード:** リモート会議・面接前チェック。信頼度向上を優先。
- **恋愛モード:** デート前チェック。親しみやすさ・表情の柔らかさを優先。
- **メンタルモード:** セルフケア・自己分析。表情の緊張状態からリラックスを提案。

### 3.3 リモート会議前アドバイス機能
- **直前チェック機能:** 会議の5分前に自分の顔を映し、現在の「第一印象スコア」を算出。
- **即時改善アクション:**
    - 「眉を整える」「口角を上げる」「光源の調整」「表情の緩め方」などの具体的指示。
- **バーチャル鏡:** 調整中にガイド線（AR）を重ね、理想のポジションをナビゲート。

### 3.4 継続利用（習慣化）機能
- **FaceLog:** 日々の表情と運勢結果のログを蓄積。
- **開運レポート:** 週次・月次で、自分の「印象の変遷」と「運気の流れ」を可視化。

## 4. 非機能要件
- **セキュリティ・プライバシー:**
    - 顔画像データは端末内で完結（オンデバイス処理）し、サーバーに送信しない。
    - サーバーへ送信が必要な場合は、画像そのものではなく「数値データ」のみとし、プライバシーポリシーに明記する。
- **パフォーマンス:** リモート会議直前のため、アプリ起動から解析開始まで3秒以内を目指す。

## 5. マネタイズ計画
- **フリーミアムモデル:**
    - 無料：基本診断、今日の運勢、基本的なアドバイス。
    - 有料（サブスクリプション）：詳細レポート機能、過去のデータ比較、無制限のシーン別詳細アドバイス。

## 6. 技術スタック案（推奨）
- **モバイル開発:** Flutter または React Native（iOS/Android同時開発のため）
- **解析エンジン:** MediaPipe (Face Mesh)
- **バックエンド:** Firebase（ユーザーデータ管理・認証）
- **UI:** 直感的で高級感のあるダークモード基調のデザイン

## 7. 開発フェーズ（ロードマップ案）

| フェーズ | 内容 |
| :--- | :--- |
| **Phase 1 (MVP)** | 顔のパーツ位置取得、シンプルな診断ロジックの実装、リモートチェックUI |
| **Phase 2 (UX向上)** | ARガイドの導入、カテゴリー選択機能の拡充、履歴管理 |
| **Phase 3 (収益化)** | 有料会員限定レポート機能の追加、サブスクリプション実装 |
| **Phase 4 (成長)** | アフィリエイト連携（推奨メイク用品等）、UIの洗練化 |
