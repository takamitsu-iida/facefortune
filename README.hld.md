# FaceFortune 概要設計書（Webブラウザ版）

## 1. システム構成
- **フロントエンド:** React (Next.js)
- **言語:** TypeScript
- **顔解析ライブラリ:** MediaPipe Face Mesh (JavaScript/WebAssembly)
- **ホスティング:** Vercel (高速デプロイ・グローバルCDN)

## 2. システム・アーキテクチャ図
```
[User Browser]
    |
    |-- (1) Webカメラアクセス (MediaDevices API)
    |-- (2) 顔解析処理 (MediaPipe Face Mesh)
    |-- (3) 占いロジック (TypeScript)
    |-- (4) UI表示 (React)
    |
[State Management]
    - React Context / Zustand (顔の座標データ、現在のモード、診断結果の保持)
```

## 3. 主要モジュール設計

### 3.1 `CameraModule`
- **役割:** ブラウザのWebカメラ映像を取得し、リアルタイムでストリームを保持。
- **仕様:** `navigator.mediaDevices.getUserMedia` を使用し、カメラ権限の取得と描画を行う。

### 3.2 `FaceAnalyzer`
- **役割:** カメラからのフレーム画像を受け取り、顔のランドマーク（468点）を解析。
- **解析指標:**
    - 目の開き具合（信頼感・覚醒度）
    - 口角の角度（親しみやすさ）
    - 眉の高さ・左右差（リーダーシップ・緊張感）

### 3.3 `FortuneEngine`
- **役割:** 解析データを受け取り、現在選択中の「モード」に応じた診断結果テキストを生成。
- **ロジック:**
    ```typescript
    // 例: ビジネスモードの場合
    if (mouthAngle < THRESHOLD) {
        return "口角を少し上げると、説得力が増し信頼度が上がります。";
    }
    ```

### 3.4 `UILayout`
- **Header:** 現在のモード表示、占い結果表示エリア。
- **Main:** 自分の顔が映るミラー画面（中央）。
- **Footer:** カテゴリー選択ボタン（ビジネス / 恋愛 / メンタル）、占い実行ボタン。

## 4. UI/UXフロー
1.  **起動:** アプリにアクセスし、カメラの使用を許可。
2.  **選択:** 「リモート会議（ビジネス）」等の目的を選択。
3.  **解析:** 解析ボタン押下後、3秒間読み込み（ローディング表示）。
4.  **結果提示:** 画面上部にアドバイスをオーバーレイ表示。
5.  **調整:** アドバイスに基づき身だしなみを調整。

## 5. データフロー
- **データの非保存:** 顔画像データはブラウザのメモリ上でのみ処理される。
- **解析数値:** 診断に必要な「数値（角度や距離）」のみを計算に使用し、サーバーには保存しない（プライバシー設計）。
